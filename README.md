## Custom Void packages
This repo contains custom templates I have written for personal use to build and install things
not included in the Void main repositories. It also includes my configurations and patches for suckless-style software.

### Usage
Copy the package you want to install into the ```srcpkgs``` directory of your local clone of the [void-packages](https://github.com/void-linux/void-packages) repo,
then follow the standard procedure for building and installing a package using ```xbps-src```.
